# randomfilegenerator
Creates as many files/folders as you request, using random filenames, foldernames, and file content. Totally useless unless you need a bunch of files ....

Simply run the randomFiles.py script and it will ask you what it needs to know before running. You will be asked how many folders, files, and levels you want to create, and also informed of the total number of files and folder that will be created, together with the amount of diskspace those files will take.
